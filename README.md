# Book Downloader

App desktop per scaricare i propri libri digitali dai servizi supportati.

## Installazione su Windows

1. Apri [Releases](../../releases/latest) e scarica il file che termina in `-setup.exe` dalla sezione **Assets**. Non scaricare **Source code**.
2. Apri il file scaricato e segui l'installazione. Non servono Python né privilegi di amministratore.
3. Avvia **Book Downloader** dal menu Start, scegli il servizio e accedi con il tuo account.

L'installer gratuito non è firmato: Windows potrebbe mostrare un avviso SmartScreen. Procedi solo se hai scaricato il file dalla Release ufficiale di questo repository. Per altri dettagli, leggi la [guida utente](docs/GUIDA-UTENTE.md).

GitHub Pages non esegue questa app: il download è nella sezione **Releases**.
