# Guida rapida (budget €0)

## Windows: avviso SmartScreen
1. Doppio clic installer → compare "Windows ha protetto il PC".
2. Clic "Ulteriori informazioni" → "Esegui comunque".

## macOS: primo avvio
1. Trascina app in Applicazioni.
2. Clic destro sull'app → "Apri" → "Apri" (una sola volta).
3. Ad-hoc signing evita errore "app danneggiata"; notarizzazione esclusa (99$/anno).

## Uso
Apri l'app → scegli il servizio → accedi → seleziona i libri → Scarica.
La cartella predefinita è `~/Books/Downloader`; puoi cambiarla da **Dove salvo i download**.
